# Kikicast 0.1.0 Preview 1

这是 **0.1 首个公开预览版，不是功能完整或已完成全部原生验收的稳定版**。

## 安装

- Windows 11 x86_64：`Kikicast-0.1.0-preview.1-windows-x86_64-setup.exe`。
- Windows 11 aarch64 / ARM64：`Kikicast-0.1.0-preview.1-windows-aarch64-setup.exe`。ARM64 设备优先选这个版本。
- 都是 **Setup.exe 安装程序，不是免安装 ZIP**；自带 .NET 10 Windows Desktop Runtime，无需另装 .NET。
- 默认当前用户 `%LOCALAPPDATA%\Programs\Kikicast`，无需管理员权限；创建开始菜单 Kikicast、说明和卸载入口，也可在 Windows 设置 → 应用中卸载。没有默认桌面图标、开机启动、文件关联或自动更新。
- 默认安装后不自动启动；可在完成页主动勾选启动。普通启动只在托盘，**双击 Ctrl** 呼出；托盘菜单打开设置/退出。先退出旧实例再升级/卸载；安装器不会强制关闭进程。
- 卸载保留 `%USERPROFILE%\.config\kikicast\` 的配置、历史、命令；不自动删除个人数据。两个架构使用同一产品身份，切换架构会更新同一个安装，不产生双份配置。
- Shell 和保存命令需要单独安装 PowerShell 7（`pwsh.exe` 在 PATH）。没有时其他功能仍可用，执行时提示缺失。

**此预览版未做可信 Authenticode 签名**，Windows 可能显示 SmartScreen/未知发布者提示。请从本仓库 Releases 下载并核对 SHA-256；不要关闭系统保护。校验文件只能核对下载完整性，不等于可信签名。

## 已接入

应用/Start menu/受限本地范围/App Paths/当前用户包装应用搜索，拼音与别名、收藏/建议、同窗口 Ctrl+K Actions、逐条全局键；基础计算/法币转换/历史；交互 PowerShell 和位置参数命令库；32 个窗口动作、Restore、自定义 DIP/百分比尺寸、半动作尺寸/显示器循环、布局编辑/捕获/预览/保存/取消。

布局打开缺失应用/本地文件或文件夹/URI/deeplink/字面 argv 必须先逐布局显式启用，默认关闭；只认领新窗口，不把旧文档窗当成功。值是明文可信启动配置，不是沙盒，不应保存秘密。原 `.lnk` 参数不改，快捷方式额外输入以及包应用 argv/文件夹明确拒绝；包装应用文件/协议使用公开契约，不回退默认浏览器/文件关联。

## 验证范围与已知限制

源码自动测试与自有桌面 smokes、发布 apphost smokes、受控安装/开始菜单/同身份升级/卸载检查由打包流程强制执行。ARM64 宿主上的 x64 测试是 Windows x64 **仿真**，不冒充原生 x64 实机验收。安装器引擎来自 Inno Setup，为 x64（ARM64 上仿真），应用/runtime 载荷分别是真正 x64 / ARM64。受控安装检查使用相同配方/载荷的私有 AppId/mutex/开始菜单组，避免覆盖已有安装；不替代用户真实配置下的最终安装签收。

物理双 Ctrl/真实 IME/TSF、混合 DPI、实时拔屏/旧 Restore/重连、一般第三方/管理员窗口、受控实包激活/更新/卸载匹配、原生 x64 实机和未辅助安装验收仍未完成。历史同 DPI 真实双屏、自有窗口与拔屏后新进程回归不代表上述场景通过。

Rooms/切换器、剪贴板/Quicklinks/Snippets/Notes/Emoji/文件搜索、高级计算、剩余系统/高级工具、完整备份/引导/设置搜索/更新仍待实现。大目录搜索端到端性能和完整安全审核也未签收。完整阻塞表见包内 `release-readiness.json` 和仓库 `docs/release-checklist.md`。
