# Kikicast 0.2.0 Preview 1

这是 **未签名、功能仍不完整的 Windows 预览版，不是稳定版或完整 Tinycast 验收**。原 `0.1.0-preview.1` 标签/安装包保留，不覆盖。

## 下载与安装

- Windows 11 x86_64：`Kikicast-0.2.0-preview.1-windows-x86_64-setup.exe`。
- Windows 11 aarch64 / ARM64：`Kikicast-0.2.0-preview.1-windows-aarch64-setup.exe`；ARM64 设备优先选原生载荷。
- **当前用户 Setup.exe，不是免安装 ZIP**，自带 .NET 10 Windows Desktop Runtime，无需另装 .NET/管理员权限。默认 `%LOCALAPPDATA%\Programs\Kikicast`，创建开始菜单和 Windows 应用卸载入口。
- 先从托盘退出旧 Kikicast，再升级或卸载；安装器不强制结束进程。延续同一产品身份/安装目录；个人配置、历史、命令仍保留在 `%USERPROFILE%\.config\kikicast\`。Debug 配置独立。
- 默认登录自启关闭，普通启动只到托盘，双 Ctrl 呼出。安装后也不默认启动；完成页可主动勾选。
- Shell/自定义 PowerShell 命令才单独需要 PowerShell 7；主程序和 RandomWallpaper 扩展不依赖外部 .NET/PowerShell/旧壁纸 helper。

**未做可信 Authenticode 签名**：可能出现 SmartScreen/未知发布者提示。仅从官方 Releases 下载并核对 SHA-256；不要关闭 Windows 安全保护。哈希证明字节完整性，不代表签名或安全沙盒。

## 相比 0.1 新增

- **Windows/.NET 扩展 SDK 1**：独立自包含进程、`.kikicast` 包、官方 GitHub Releases 目录、兼容架构/最低宿主/协议过滤、导入/安装/更新/启用/卸载；声明式布尔选项和 UUID 文件夹设置。安装、列出、编辑、保存、更新与启动均不执行扩展命令。
- **RandomWallpaper 0.1.0-preview.3** 在 [扩展仓库 Releases](https://github.com/kekeqwq/kikicast.extensions/releases/tag/v0.1.0-preview.3) 单独分发，不随主安装包隐式启用。Settings → Extensions → Refresh 可选官方包，或 Import `.kikicast` 手动导入；安装可执行代码需确认，首次安装默认禁用且没有个人壁纸路径。
- 具名文件夹随机桌面/锁屏壁纸、持久化 shuffle bag/源图身份/独立目标结果。DeleteNow 要新确认，当前文件夹无不同有效图片时尝试其他已启用文件夹；先替换并核验所有仍引用源图的目标，再显式回收到回收站。通过公开原始文件引用核验，避免 Windows 锁屏图像流转换误判。外部修改、部分替换、不可核验或中断状态保守拒绝；没有永久删除回退。
- **General → Start at Windows sign-in** 默认关闭：公开当前用户 Run 项、当前渠道/保存位置所有权、读回、保存失败补偿，保留外部同名注册。只启动托盘，不执行壁纸/扩展命令；Windows 启动策略可阻止或延迟，应用不绕过它。卸载仅清理精确属于当前安装的启动命令。
- **统一彩色类别矢量图标**：扩展/窗口管理/布局/自定义命令等十一类，固定图标位和标题/副标题列；原应用图标优先，缺失时降级。明暗/高对比资源，不新增 IO 或执行。

保留 0.1 的搜索/拼音/别名/收藏/建议、Ctrl+K Actions、逐条全局键、计算/法币/历史、交互 Shell/参数命令、32窗口动作/Restore、自定义尺寸/半动作循环、默认关闭的布局缺失应用和新窗口文件/URI/字面 argv。
