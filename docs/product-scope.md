## 明确不做

- Raycast 扩展运行时、扩展市场和兼容宿主 API。
- Apple Shortcuts、Finder、Dock、Apple Events 等 macOS 专属能力。
- macOS 原生全屏的通用等价实现；不统一发送 F11。
- macOS Spaces 手势及无动画切换；Windows 虚拟桌面切换不是必需项。
- 任意普通字母双击作为默认快捷键；避免输入 `aa` 误触发。
- 系统范围 Hyper 键重映射不在当前必需范围，若以后增加须另做需求和冲突验证。
- Raycast 配置导入不是首要交付；不因去掉扩展运行时就假定其他导入自动兼容。
- 上游捐赠提醒、品牌社交入口等非产品操作能力。

## 阶段出口

### P1：可运行的核心闭环

固定稳定 SDK；建立 Core / Windows / App / Tests 工程。实现单实例/托盘、设置落盘、热键录制与冲突、双击 Ctrl、主面板、应用索引启动、搜索排序、基础计算。必须完成焦点和 IME 验收。

### P2：窗口管理是核心，不是可选附件

先几何和恢复，再多屏/DPI，再自定义尺寸和布局编辑器。当前自定义尺寸、显示器循环与[已打开窗口布局](window-layouts.md)的编辑/预览/捕获/保存/实际摆放已实现；缺失应用启动已用默认关闭的逐布局选项/真实保存/来源门禁/限时事件等待接入，文件/文件夹、URI/deeplink与字面argv输入现通过真实字段/保存/门禁/新窗口事件等待接入直接EXE或包公开契约；lnk额外输入/包文件夹或argv明确拒绝，受控包激活/更新匹配与第三方验收仍待补，不能称布局全兼容完成。以多屏、固定尺寸、管理员窗口实测通过为出口。

### P3：日常工作流

自定义命令、剪贴板、Quicklinks、手动 Snippets、Notes、Emoji/颜色、文件搜索、窗口切换、系统动作、高级计算及分类备份。每个功能补齐开关、统一动作入口与测试后再接入面板。

### P4：高级能力与发布

Rooms、关键词展开、原位 Markdown、OCR、AI/MCP、日历会议等按可行性落地。补齐发布、更新、安全回归和性能实测；不可可靠实现的功能记录原因，而非静默删掉。

## 默认值

- 面板及应用搜索始终可用；新配置建议绑定双击 Ctrl，允许启动时改为组合键。
- 剪贴板按上游默认开启，但首次启动明确告知采集范围并允许立即关闭。
- 窗口管理及其他可选功能按上游默认关闭，可在引导中主动开启。
- AI、自动展开、OCR、自动入会、任意 shell fallback 均不通过导入自动开启。
- “显示在搜索中”不等于“启用”：隐藏条目仍可由快捷键执行；功能关闭时所有入口都必须受阻。
