# Release gate — not a release declaration

`release-readiness.json` 是机器可读的阻塞表。目前不是“完整 Tinycast 可发版”。功能矩阵、自动测试数量、阶段性可运行 EXE 都不等于最终人工签收。

## Automated package path

```powershell
# Explicit incomplete prerelease only; all build/test/desktop checks must still pass.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -Preview -Runtime win-arm64 -Version 0.1.0-preview.1 -InnoCompiler '<verified Inno Setup 7.1.0 ISCC.exe>'
# ARM64 only: explicit x64 emulation, not native x64 acceptance:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -Preview -CrossPublishPreview -Runtime win-x64 -Version 0.1.0-preview.1 -InnoCompiler '<verified ISCC.exe>'

# Stable: mandatory manifest checks passed, clean committed tree, trusted certificate.
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -Runtime win-arm64 -Version 0.1.0 -SignTool '<Windows SDK signtool.exe>' -CertificateThumbprint '<trusted signing certificate>'
```

Gate behavior:
- Reject missing/duplicate/invalid readiness checks; portable mandatory checks cannot be excluded.
- Refuse stable packaging while any mandatory check is pending. A preview must have a prerelease version and is labelled incomplete.
- Build in a unique temporary output (does not overwrite or stop the user's running instance); warnings are errors.
- Run both test projects, four full desktop smoke modes, and verify the published apphost too. No failed smoke is silently skipped.
- Stable native architecture gate remains. Explicit preview x64-on-ARM64 validation is **emulated**, not native x64 acceptance. Self-contained apphost/runtime PE architecture is checked; .NET bundled, pwsh optional/separate.
- Produce Inno Setup **Setup.exe**, per-user installation/Start menu/HKCU uninstall and same identity across architectures; no elevation/autostart/force-close. Published full smokes and private-identity same-payload installer/start-menu/upgrade/installed apphost/uninstall checks are required. See [installer contract](installer.md).
- Stable signing uses a user-provided trusted certificate/signtool and timestamp, verifies Authenticode. No self-signed certificate masquerades as trusted signing.
- Include LICENSE/NOTICE/third-party licenses, incomplete-check manifest, settings matrix and requirements; never package user config/history/scripts/credentials/cache.
- Write payload hashes plus Setup.exe SHA-256; never overwrite an existing artifact. No tests/fixtures/debug/user data shipped. Publication requires clean committed source/exact pushed annotated tag, draft-first release and verified remote asset digests. Upload only setups/checksums/sanitized validation, no local screenshots or settings.

Current script syntax and negative stable gate have been verified. 0.1 targets two Setup.exe assets, no portable ZIP; GitHub release status indicates publication, not build success. Current ARM64 owned-click/injected-input full smokes pass; unassisted package smoke/physical acceptance remain separate pending gates.
