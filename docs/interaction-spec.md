# 交互规范

状态：计划中的行为合同；实现偏离须更新本文并说明原因。

## 1. 跨平台键位规则

macOS 的应用内 Command 操作优先映射 Windows Ctrl：动作菜单 Ctrl+K、收藏 Ctrl+Shift+F、收藏槽 Ctrl+1…9/0、复制结果 Ctrl+C。Option 优先映射 Alt。映射产生冲突时单独设计，不机械叠加修饰键。

全局快捷键由用户录制，不直接转换 Carbon 数字键码。默认双击 Ctrl；左右侧选择属于 Windows 扩展设置。界面上显示的快捷键必须从实际绑定/命令元数据生成。默认仅呼出键已绑定，Alt+Space 和窗口动作全部未绑定；已有配置不静默清空，提供显式恢复默认。设置按“全局配置 / 窗口管理配置”分 Tab，逐行点击录制，不使用动作下拉框。

## 2. 呼出与关闭

0. 正常启动仅驻留托盘；只有快捷键呼出主界面，托盘仅负责设置和退出。呼出只做一次有界前台激活并聚焦输入框；失败立即关闭并提示，不循环抢焦点。输入框随后失焦、点击空白或窗口失活，都按再次按快捷键的关闭流程处理。
1. 呼出前保存前台窗口及可校验的进程身份。
2. 面板出现在配置的屏幕（鼠标屏幕或目标窗口屏幕），固定顶部锚点，展开时向下生长。
3. 激活搜索输入并强制英文键盘，禁用本搜索框输入法组合输入；不修改其他应用线程的键盘布局。关闭时恢复呼出前捕获的目标窗口、键盘布局及可读取的 IME 开关/转换状态；读取不到 TSF 状态时不猜测或轮换。隐藏任务栏条目，不连带激活设置/笔记窗口。
4. 再次呼出切换关闭；切换到其他功能则打开该模式。
5. Esc 先关闭动作菜单/弹层，再返回导航上一层，再关闭面板；根搜索直接关闭。
6. 关闭并未执行切换应用操作时尽力恢复原窗口；原窗口已消失时不激活其他随机窗口。
7. 执行打开应用、切换窗口、布局等操作时不恢复旧焦点覆盖新目标。
8. 普通焦点丢失关闭面板；自身对话框/菜单的焦点转移不能被误判成外部失焦。

紧凑模式只在根搜索为空时生效；输入后展开。搜索框保持同一实例，不能因切换模式/尺寸重建导致查询和焦点丢失。

## 3. 双击修饰键

按上游 `DoubleTapDetector`：每次按住不超过 250 ms，第一松开至第二按下不超过 300 ms；第二松开触发。

- 两次都必须是单独修饰键；期间普通键、鼠标按下或其他修饰键取消。
- 忽略自动重复；长按不触发；Ctrl+C/Ctrl+V 等不构成 tap。
- 同时持有左右 Ctrl 不算单独点击；侧别设置明确决定可否混用。
- Caps Lock 锁定状态不取消 Ctrl 双击。
- 注入事件不触发绑定；会话切换、锁屏、睡眠、录制开始/结束均清除半完成状态。
- 不吞掉普通 Ctrl 事件；不储存原始按键或输入文字。
- 录制期间暂停动作执行，录制界面和全局监听共用纯识别器。
- 普通键双击、Fn/Globe 不提供默认绑定；Fn 通常由硬件处理。

## 4. 根搜索与结果

一个查询可以同时产生计算卡、上下文动作、索引结果和 fallback。

显示顺序：可行动计算卡 → 识别出的上下文动作（例如打开 URL）→ 排序后的索引结果 → 用户开启的 fallback。空查询为收藏、建议及各类型分组；完整分组顺序由唯一行模型决定。

- 上下键移动、鼠标点击执行；输入查询重置到本模式的初始选择。
- 分组标题不是行，不占选择索引；每行 ID 唯一。
- 别名、标题、备用标题、子标题、关键词区分字段；保留上游评分、frecency 和确定性排序规则。
- 中文名称支持全拼、首字母及字符子序列匹配；当前使用 TinyPinyin.Net，索引时构造拼音字段，按 NFKC/大小写/空白归一化。不保证所有多音词与罕见字；重音及完整上游 ICU 排名仍待对齐。
- 收藏顺序独立于搜索排序；Ctrl+1…9/0 对应可见收藏槽，键码跟随物理数字行。
- Ctrl+K 打开当前结果动作菜单；只显示当前条目确实支持的动作。
- 隐藏搜索结果保留别名、收藏及绑定；恢复入口在设置中。
- URL/路径识别不能自动执行 shell；fallback 仅在显式 Enter 时执行。

## 5. 计算器

逐次输入计算；完整表达式回答，不完整/不适用输入尽量保持安静。纯数字通常保持应用搜索，明确算式才显示结果。尾部运算符保留最近完整前缀答案；非法括号不猜结果。

计算卡可行动时默认选中，Enter 复制并写入历史，不自动粘贴到原应用。明确的单位不兼容可显示错误卡，错误卡不可执行。显示舍入不能反馈到下一次运算。

数字格式由显式设置/系统区域注入；英文语法和本地数字格式分离。时区、时钟和汇率也是注入输入，不能每次输入发起网络请求。

## 6. 参数及命令

需要参数的结果在搜索框旁显示参数输入，不离开该行。Tab/Shift+Tab 优先走参数字段；缺少必填值时 Enter 聚焦第一项而不执行。

由快捷键执行带参数命令时打开面板到该命令并聚焦缺项。收集完整后再显示一次确认。全局快捷键、结果行、收藏、设置测试按钮都经过同一执行入口。

自定义命令区分“可执行文件+参数”和“shell 脚本”。不将用户参数作为脚本源代码插值；PowerShell/cmd/WSL 分别定义安全传参规则。输出窗口关闭不停止进程；Stop 只停止自己拥有的进程树；重跑保留原调用信息。

## 7. 模式导航

从已打开的面板进入功能：保存查询/选择作为返回帧。从隐藏状态用功能快捷键进入：作为该模式根，不带虚构返回帧。

根搜索 → AI → 剪贴板 → 根搜索为上游 Tab 环；关闭的功能跳过。参数字段、菜单、Rooms 自定义 Tab 优先于模式环。尚未实现的模式不占环。

一般模式同键再次触发关闭；窗口切换例外：再次触发步进选择。仅当步进且修饰键仍持有时，松开才确认；双击 Ctrl 等已经松开的绑定依赖 Enter，不虚构松键确认。

## 8. 剪贴板与文本输入

默认 Enter 粘贴，Ctrl+Enter 复制，Ctrl+Alt+Enter 纯文本；用户更改默认动作时按上游交换规则统一调整菜单、双击和固定槽。冲突由模式优先级解决，不让根搜索的 Ctrl+Enter 动作抢走粘贴。

关闭面板、恢复目标、确认目标未换后再发送粘贴；目标已关闭或不允许输入时不向新前台乱发。内部写入携带标记，不能循环采集。临时替换剪贴板后仅在内容未被用户改变时恢复。

自动片段展开默认关闭；不得在密码框、本应用搜索/设置字段、IME 组合阶段触发。无法判断安全性时不自动展开，仍允许显式手动插入。

## 9. 窗口操作与 Rooms

从面板执行窗口命令使用呼出前目标；直接热键使用当前目标。自己临时浮层不进入窗口清单。

保持上游几何语义：分数分屏、边缘完整 gap/内部半 gap、按边缘舍入、放大缩小按屏幕步长、单级恢复、半屏可选尺寸/显示器循环。

自定义尺寸当前已接入：DIP/百分比各轴独立、九锚点及偏移、Keep draft → Save changes、稳定UUID、共享主门/Enabled/Restore；窗口搜索显示关闭和逐条隐藏不禁用快捷键。单位切换按设置所在屏转换，执行按目标屏净工作区。见 [适配合同](custom-window-sizes.md)。半屏显示器循环已按None/Sizes/Displays三模式接入：[合同](window-display-cycle.md)明确双槽带、原始屏计步、单屏不翻边、模式/拓扑重置与旧bool配置兼容；真实同DPI双屏自有tour已验收，混合DPI/实时hotplug仍待。[已打开窗口布局](window-layouts.md)已实现编辑/预览/捕获/复制/保存/实际摆放和统一绑定，缺失显示器始终跳过；每布局默认关闭的Launch missing applications启用并保存后，仅缺失当前应用经过同一安全启动器提交，再限时窗口事件等待并摆放。保留原快捷方式参数/每实际app至多一次，不创建或覆盖Restore点，取消不终止已打开应用。文件或链接额外参数和Rooms仍未实现。

布局缺少显示器时跳过，不按名字/序号猜测或把多屏布局挤到主屏。Keep entry → Keep layout draft → Save changes；预览不移动窗口。Settings 的 Apply saved layout 默认No确认关闭设置并丢弃未保存草稿，使用当前保存定义进入同一执行门。独立显示开关/隐藏不禁用绑定，Enabled及窗口/应用主门阻止执行。托盘可取消剩余布局摆放；已成功摆放不假装原子回滚。Rooms 的其他窗口采用记录后最小化，只恢复由本程序改变的状态；用户原先最小化的窗口不擅自恢复。

## 10. 视觉与可访问性

相似的圆角面板、搜索栏、图标/副标题、分组、结果卡、底部动作提示及紧凑收藏条。尺寸/颜色/动效采用统一 token，待与上游截图和源码核对后固定，不凭空声称像素一致。

外观跟随系统亮暗主题和强调色，隐藏滚动条但保留滚动。主面板使用分层窗口的逐像素透明：无硬边框与方形底衬，外围仅柔和暗色阴影，面板填充半透明。不使用 DWM 亚克力或 WindowChrome，避免方形底衬。使用降低透光度的 tint 和呼出前内存背景快照，背景 Image 模糊、文字不模糊；关闭释放，从不存盘，不实时刷新。高对比度/系统透明关闭时使用实色。支持高对比度、缩放、减少动画、键盘全操作和 UI Automation 可访问名称。使用可再分发图标库，不复制 Apple SF Symbols 系统素材。
